JavaCoreSandBoxЭтот репозиторий представляет собой набор самостоятельных проектов и микро-сервисов, 
демонстрирующих владение базовым и продвинутым инструментарием Java Core, а также реляционными базами данных. 
Кодовая база разработана с фокусом на Enterprise-стандарты, чистую архитектуру и отказоустойчивость.

Стек технологий
Язык: Java 17/21.
Базы данных: PostgreSQL (изолированное развертывание инфраструктуры через Docker-контейнеры).   
Тестирование: JUnit 5, Mockito.
Сборка: Maven/Gradle.

Каждый раздел репозитория решает изолированную техническую задачу:
SQL Project: Проектирование структуры реляционной базы данных (schema.sql, seed.sql), написание сложных DDL/DML запросов, использование JOIN и нормализация таблиц (1НФ-4НФ).   
Multithreading Project: Асинхронные вычисления, управление пулами потоков и обеспечение потокобезопасности при параллельной обработке данных.
Testing Project (OrderService): Покрытие бизнес-логики модульными тестами, изолирование зависимостей с помощью Mockito, устранение "магических чисел" и строк в рамках рефакторинга.
Stream API: Сложная фильтрация, маппинг и декларативная обработка коллекций данных.
Collections & Exceptions: Разработка ядра системы учета (телефонная книга) с применением оптимальных структур данных (Map, Set, List), кастомными валидаторами и собственной иерархией исключений для безопасной обработки ошибок.

Инженерная культура и WorkflowПроект поддерживается в соответствии с профессиональными индустриальными практиками:   
Изоляция изменений: Каждая новая функциональность разрабатывается в отдельной feature-ветке.   
Code Review: Интеграция кода в main происходит строго через оформление и проверку Pull Requests.   
Атомарные коммиты: Вся история контроля версий ведется в строгом соответствии со стандартом Conventional Commits (использование префиксов feat:, refactor:, test:, chore:).
