# Java Core & SQL Architecture Portfolio

Этот репозиторий представляет собой коллекцию независимых сервисных модулей и микро-проектов, демонстрирующих уверенное владение базовым и продвинутым инструментарием Java, а также проектированием реляционных баз данных. 

Кодовая база разработана с упором на Enterprise-стандарты, чистую архитектуру и надежность.

## Стек технологий

* **Язык:** Java 17/21.
* **Базы данных:** PostgreSQL (изолированное развертывание инфраструктуры через Docker-контейнеры).   
* **Тестирование:** JUnit 5, Mockito.
* **Сборка:** Maven / Gradle.

## Архитектура проектов и модулей

Каждый раздел репозитория решает изолированную инженерную задачу:

* **SQL Project:** Проектирование структуры реляционной базы данных (разделение скриптов на `schema.sql`, `seed.sql`, `queries.sql`), написание сложных DDL/DML запросов, использование JOIN и нормализация таблиц (до 4НФ).   
* **Multithreading Project:** Асинхронные вычисления, управление жизненным циклом потоков и обеспечение потокобезопасности при параллельной обработке данных.
* **Testing Project (OrderService):** Покрытие бизнес-логики модульными тестами, изолирование внешних зависимостей, устранение "магических чисел" и строк в рамках глубокого рефакторинга.
* **Stream API:** Декларативная обработка коллекций, сложная фильтрация и маппинг структур данных.
* **Collections & Exceptions:** Разработка ядра системы маршрутизации данных (телефонная книга) с применением оптимальных структур (Map, Set, List), кастомными валидаторами и собственной иерархией исключений для безопасной обработки отказов.
